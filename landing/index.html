آلية العمل

من الصوت إلى الرؤية في 4 خطوات

تدفّق سلس ومؤتمت بالكامل — من لحظة بدء المكالمة حتى وصول التحليل للوحة الدور المناسب.

1

بدء المكالمة

يلتقط النظام صوت المكالمة المباشرة لحظة انعقادها بين العميل والموظف.

2

تفريغ فوري

يُحوَّل الصوت إلى نصّ لحظيًا عبر Whisper المحلي المسرّع بالـ GPU.

3

تحليل ذكي

يحلّل نموذج لغوي محلي النص لاستخراج المشاعر والتصنيف والتقييم.

4

عرض حسب الدور

تظهر النتائج لحظيًا في لوحة كل دور حسب صلاحيته.

الأسئلة الشائعة

كل ما تريد معرفته عن SCM

هل يدعم النظام تحليل المكالمات باللغة العربية؟

نعم. النظام مبني بشكل أساسي حول اللغة العربية — التفريغ الصوتي عبر Whisper يدعم اللهجات العربية، وواجهة المستخدم والتقارير ثنائية اللغة (عربي/إنجليزي) بالكامل.

أين تتم معالجة البيانات؟ هل تُرسل لأي خدمة سحابية؟

كل المعالجة تتم محليًا على خوادمك — التفريغ عبر Whisper والتحليل عبر نموذج لغوي محلي (LM Studio أو Ollama). لا يُرسل أي صوت أو نص لأي API خارجي، مما يجعله مثاليًا للجهات الحسّاسة للبيانات.

ما المتطلبات التقنية لتشغيل SCM؟

خادم بكرت شاشة NVIDIA للتفريغ المسرّع (يعمل على المعالج أيضًا بأداء أبطأ)، نموذج لغوي محلي عبر LM Studio أو Ollama، وقاعدة بيانات Supabase. النظام يعمل بضغطة واحدة على ويندوز.

كيف يحصل كل موظف على الصلاحيات المناسبة؟

النظام يعتمد صلاحيات دقيقة حسب الدور (موظف، مشرف، مدير، أدمن) عبر مصادقة JWT. كل مستخدم يرى فقط البيانات التي تخصّ دوره ونطاق مسؤوليته، مع سجل تدقيق كامل لكل إجراء.

هل يمكن تصدير التقارير والبيانات؟

نعم. يمكن تصدير بيانات المكالمات إلى CSV، وتوليد تقارير PDF احترافية بعد كل مكالمة تتضمن الملخّص والتقييم والتوصيات — جاهزة للطباعة والأرشفة المؤسسية.
