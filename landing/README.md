# SCM — Landing Page

صفحة هبوط (Landing Page) تسويقية **مستقلة بالكامل** لمشروع Smart Call Monitor.
مصمّمة للنشر على أي استضافة ثابتة (Static Hosting) واستخدامها في الحملات الترويجية.

## المحتوى
ملف واحد مكتفٍ بذاته: [`index.html`](index.html) — كل الـ CSS و JavaScript مضمّنة بالداخل.
لا يعتمد على أي Backend أو صفحة تسجيل دخول. الموارد الخارجية الوحيدة هي الخطوط
(Google Fonts) و الأيقونات (Font Awesome) من الـ CDN.

## المميزات
- ثنائي اللغة (عربي / إنجليزي) مع تبديل فوري و RTL/LTR.
- وضع داكن / فاتح مع حفظ الاختيار في المتصفح.
- متجاوب بالكامل (Desktop / Tablet / Mobile).
- أقسام: Hero، المميزات، آلية العمل، التقنيات والمعمارية، اللوحات، الخصوصية، الأسئلة الشائعة، تواصل.

## النشر (Deployment)
الصفحة ملف ثابت — انشرها بأي طريقة:

- **Netlify / Vercel:** اسحب مجلد `landing/` (أو اربط المستودع وحدّد `landing` كمجلد النشر).
- **GitHub Pages:** ضع `index.html` في فرع/مجلد النشر.
- **أي استضافة:** ارفع `index.html` إلى الجذر.

### معاينة محلية
```bash
cd landing
python -m http.server 8000
# ثم افتح http://localhost:8000
```
